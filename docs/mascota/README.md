# Hubi, la mascota

Tres poses con fondo transparente, recortadas de las imágenes generadas con la paleta de la app:

| Archivo | Expresión | Uso previsto |
| --- | --- | --- |
| `hubi-feliz.webp` | Saluda con una caja en alto | Paquete entregado, lista vacía |
| `hubi-sorprendido.webp` | Sorprendido, con la caja en brazos | Incidencia |
| `hubi-enfadado.webp` | Brazos cruzados | Sin movimiento, error |

Paleta: gorra terracota `#E8663A`, sudadera mostaza `#F0B64E`, pantalón cacao `#8B5A35`, zapatillas crema `#F7F0E3`, cajas cartón `#C98A4B`, detalles `#2B2118`.

Aún no se usa en la interfaz. El recorte del fondo verde croma se hizo con un script que elimina el color de fondo y el reflejo verde de los bordes; si se generan poses nuevas con fondo verde liso `#00B140`, se pueden recortar igual.
